## 一、🔴 必须处理：`UpdatePluginTask`（高危，建议立即禁用或修正）

### 问题
`ScheduledTask/UpdatePluginTask.cs:47`：

```csharp
private static string RepoReleaseUrl =>
    "https://api.github.com/repos/sjtuross/StrmAssistant/releases/latest";
```

你的社区版仓库是 **`myp015/StrmAssistant`**，但这个自更新任务拉取的是 **PRO 官方 `sjtuross/StrmAssistant`** 的 release。

### 危害链（已读代码确认）
1. 每周**随机触发一次**（`GetDefaultTriggers`，`TriggerWeekly` + 随机日/时）。
2. 若远端 tag 版本 **高于**你的 `Plugin.CurrentVersion`（`3.0.55`），进入更新分支。
3. 第 136-143 行：**直接以 `FileMode.Create` 覆写 `plugins/StrmAssistant.dll`**（你自己的插件文件！）。
4. 第 157 行：`NotifyPendingRestart()` → **触发 Emby 重启**。
5. 结果：你的社区适配版被 **PRO 版 DLL 覆盖**，重启后插件可能直接崩（PRO 依赖 `BlurayMounter`/`Portable.Licensing` 等你没有的 dll）。

> 这类"静默替换 + 重启"一旦发生，排查会很痛苦。**风险等级：高。**

### 处置建议（三选一）

| 方案 | 做法 | 适用 |
|---|---|---|
| **A（推荐）· 直接移除任务** | 删除 `UpdatePluginTask.cs`，并移除注册 | 你若用 GitHub Actions（`build-N`）手动更新，此任务无意义 |
| **B · 改指向自己的仓库** | `RepoReleaseUrl` 改为 `https://api.github.com/repos/myp015/StrmAssistant/releases/latest`，且 asset 名匹配你自己的发布产物 | 你想保留自更新能力 |
| **C · 关掉默认触发** | `GetDefaultTriggers()` 返回空（`yield break`），改为纯手动任务 | 想留代码但不自动跑 |

> ⚠️ 注意：B 方案还要求你的 release tag 版本号体系与 `ParseVersion` 兼容（当前用 `new Version(...)`，tag 必须是 `3.0.0.x` 形态；若你的 release 是 `build-N`，会解析失败抛异常）。

- **问题**：社区版的"关于"页把用户导到 PRO 官方仓库，容易造成困惑（用户以为下的是 PRO）。
- **建议**：改为指向 `myp015/StrmAssistant`（你的仓库），或保留 Wiki 指向 PRO（因为 Wiki 内容确实通用）。
- **风险**：低。纯展示。

### 2-2 · `IncludeExtra` 与 PRO 语义不符
- **现状**：社区 `MediaInfoExtractOptions.IncludeExtra` 是**可写 bool**（默认 false）；PRO 反编译显示它是 `=> true`（**恒真只读**）。
- **含义**：PRO 已不再提供"排除额外内容"的开关（永远包含）；社区仍保留可配。
- **建议**：**保留社区行为**（更灵活），或在描述里注明差异。**不建议**改成恒真——会丢失现有能力。
- **风险**：无。

## 五、审计方法学说明（为什么没有发现"大面积死代码"）

1. **所有 Mod patch 类**（35 个）都在 `PatchManager.cs` 有注册命中（命中数 2-5），并通过 `PatchTracker` 管理生命周期。
2. **所有 Core 类**（12 个）都被 1-5 个文件引用。
3. **所有功能开关**最终都汇到 `Plugin.cs` 的启动流程或 `Options/Store/*.cs` 的变更回调。
4. patch 全部用**反射 `GetMethod` + 签名匹配**实现，配 `FallbackPatchApproach`（Harmony→Reflection→None）+ 分级告警（核心/可选），**本身具备抗 Emby 升级失效的能力**。

**唯一的真实失效风险来自"外部集成"（GitHub 仓库 URL），而非内部代码。**
