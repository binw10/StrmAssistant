## 三、🐛 BUG-1（已修复并验证）

### 现象
豆瓣 **IMDb → 豆瓣ID** 解析路径 100% 失败：Wikidata SPARQL 稳定返回 **HTTP 400**（修复前 20 次查询中 10 次 400）。

### 根因
`StrmAssistant/Provider/Douban/DoubanAssist.cs:942-943`：

```csharp
var query = $"SELECT ?doubanId WHERE {{ ... " +      // ← 有 $，{{ 正确转义为 {
            "FILTER(ISLITERAL(?doubanId)) }} LIMIT 1"; // ← 无 $！}} 原样保留 → 多一个右花括号
```

第二段是**普通字符串字面量（无 `$` 前缀）**，`}}` 不会被转义，最终 SPARQL 语法错误 → 400。

### 验证与修复

| 查询 | 修复前 | 修复后 |
|---|---|---|
| Wikidata HTTP 状态 | **400** ❌ | **200** ✅ |
| 重启后日志 400 计数 | 10 | **0** |
| 重启后日志 200 计数 | 0 | **8** |

**修复**：`}} LIMIT 1` → `} LIMIT 1`（1 字符）。全仓复核确认仅此一处误用
（`IsoMounter.cs:94/831`、`MovieDbEpisodeGroupExternalId.cs:18` 的 `}}` 均在插值串内，正确）。

**流程**：改源码 → `dotnet build -c Release`（0 错）→ 部署至 `D:\Downloads\embyserver\programdata\plugins` → `POST /emby/System/Restart` → 复测。
