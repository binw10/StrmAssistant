# 3.0.0.57 稳定性修复与回归范围

本轮针对3.0.0.57的11项问题，保留现有功能开关、程序集版本及Windows打包流程。

| 问题 | 修改后的行为 |
|---|---|
| 多版本信息接口无需登录且返回路径 | 接口要求认证，按宿主的用户媒体可见性过滤单项/批量及可解析的本地版本所属条目；响应不含Path，URL文件名标签不带查询参数 |
| 旧配置迁移晚于缓存与清理器初始化 | 先迁移旧分组及分钟值，再初始化缓存、补丁与清理器，首次启动即使用原配置 |
| 恢复任务取消后仍有工作项写库 | 停止安排新工作，等待已启动工作结束；JSON解析后及保存流程检查/传递取消 |
| 中文索引阶段二失败后无法重试 | 完成标志只在真实成功后设置；在途门闩在finally释放，后续连接可重试；失败不清除用户选项，恢复请求仅在成功后清除 |
| 旧连接工厂签名与固定两参数调用不匹配 | 支持无参、bool、CancellationToken、bool+CancellationToken，并拒绝其他签名 |
| 远程ISO响应头等待无总超时 | 总预算覆盖连接、响应头和正文，空闲读取超时取消真实I/O |
| 多片段蓝光把最长clip当整片并注入整片章节 | 明确拒绝该提取方式，保持原ISO交回宿主；禁止最长流回退及错误章节注入 |
| Windows集中备份剥除盘符/共享根造成碰撞 | 新路径保留盘符或UNC服务器/共享身份，并保存与核对源路径；未标识来源的旧Windows集中备份保留但不自动恢复 |
| 缩略图检查false/异常后ExtraType丢失 | Postfix和Finalizer恢复ExtraType及临时快捷方式状态，保留原异常 |
| 更改并发数时更换/释放正在使用的信号量 | 采用稳定实例原位调整额度；缩容先排空已有持有者，再允许新工作，不把旧额度释放到新池 |
| 选择失效媒体库时回退全库 | 显式选择未匹配库/位置时不做全库查询；强制重提取也受选择范围限制 |

## 已执行验证

- 新增17项xUnit用例，覆盖并发缩容/扩容/取消/释放、盘符与UNC路径、远程ISO响应头/正文超时和正常Range、多片段安全拒绝及单片段兼容。连同原有39项，共56项通过。
- 编译检查使用.NET SDK10、net6.0目标。macOS上跳过原项目Windows专用的资源封装和ILRepack部署目标；没有据此宣称Windows发布流程已执行。单元测试使用下述已在真实宿主加载的合并DLL，14个功能源码文件与该候选源一致。
- 真实宿主隔离验证：Linux x64、Emby4.10.1.0、.NET8.0.28，网络隔离、独立配置及数据库。测试合并DLL的SHA-256为`3851dd12e8d5f6c13cd6ddf9872bb49f017ff4a842b0744efbf924e9f4e0a6f8`。该DLL含独立的便携打包/语言资源加载适配，本PR只提交功能源码及测试，不引入该打包适配。
- 匿名多版本接口401；可见用户可取来源；受限用户单项和批量均不返回来源；响应无Path。
- 首次启动旧格式配置直接使用原任务/搜索范围，关闭的内存清理器未被默认开启。
- 真实QueuePhase2受控失败后再次触发，工厂调用数1→2，在途门闩回到0；四类工厂签名均实际被正确调用。这里是方法替代工厂测试，并非跑过四个Emby版本。
- 两条自制媒体记录参与真实恢复任务：解析阶段受控阻塞后取消，任务等工作结束才返回，取消后的字段及媒体流未被写入。正常恢复任务另行完成。
- 默认180秒下载预算在模拟响应头卡住时主动取消；185秒检查已结束，服务器190秒才主动关闭。
- 真实解析方法拒绝60+120秒多clip播放列表，路径/章节为空；false及异常分支均恢复ExtraType；真实并发限制器2→1缩容按持有者释放顺序正确唤醒。
- 媒体库选择不存在时，有媒体的合成库仍返回0候选。
- 中文增强开启后的简体、繁体、拼音及首字母6类查询均命中，32次并发查询全部成功，缓存刷新实际更新独立数据库。

## 限制与兼容

多片段ISO修复的是错误提取行为，**没有实现完整标题拼接**，宿主也可能无法提取该ISO。Windows真实挂载及文件系统、其他Emby版本、115在线播放及全新TMDB联网刮削未完整验收。Windows路径验证来自链接真实源码/反射的跨平台测试。

旧Windows集中备份如果原先清除了来源路径，就无法可靠判定属于哪个盘/共享。保留原文件，重新生成或人工核对来源后迁移；避免将其他卷的JSON误恢复到当前条目。Linux/相邻备份的原路径保持兼容。

本地xUnit使用macOS arm64的.NET10执行net8测试（roll-forward）；隔离宿主使用Linux.NET8。未把本地方法/桩测试或宿主成功初始化当成所有业务功能通过。正式服务未被本轮测试更改，测试实例均已关闭。
