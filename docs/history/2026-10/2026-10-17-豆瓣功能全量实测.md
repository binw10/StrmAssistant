### 2.1 评分端点

```
GET /emby/Douban/Ratings?Ids=6,8,190,191
→ {"Enabled":true,"Ratings":[
     {"ItemId":"6",  "SubjectId":"37560173","Rating":7.8,"Votes":35379},

     {"ItemId":"191","SubjectId":"37193250","Rating":7.3,"Votes":38275}]}

GET /emby/Douban/Ratings              → {"Enabled":true,"Ratings":[]}      ← 设计行为
GET /emby/Douban/Ratings?Ids=1..81    → 只返回 item 6（Take(80) 截断后仅 6 命中）
```

> `DoubanService.Get`（`Web/Service/DoubanService.cs:18`）逻辑：未开启 → `Enabled:false`；`Ids` 为空 → 直接返回空数组；`Ids` 解析后 `.Take(80)`。**不带 `Ids` 返回空是设计行为，不是 bug**（前端 `checkEnabled()` 正是用它探测开关）。

### 2.3 item 8「有评分却无徽章」——已查明：**不是 bug**

- 现象：item 8 `ProviderIds.Douban=37069873`、`CommunityRating=8`，但评分快照里**没有** 37069873，故徽章不显示。
- 交叉验证：带用户 Cookie 直抓豆瓣源站 `https://movie.douban.com/subject/37069873/` → HTTP 200、页面含 **「暂无评分」**、`v:average` 不存在。
- 结论：**豆瓣该条目本身就没有评分**，缓存里 `Rating=None`、快照无记录、徽章不显示 **三者全部正确**；item 8 的 8 分来自 TMDB。
- 附带发现（见优化方案 D2）：`FetchSubjectAsync` 命中缓存时**提前 return，不会补记评分快照**（`Provider/Douban/DoubanAssist.cs:976-977`），存在「缓存命中 + 快照缺失 → 徽章永久不显示」的健壮性缺口。

### 2.5 ❌ 豆瓣外部链接图标缺失（真实缺口）

```
GET /emby/Users/{uid}/Items/191?Fields=ExternalUrls,ProviderIds
ProviderIds: {'Imdb':'tt38984207','Tmdb':'1481955','Douban':'37193250'}
ExternalUrls:
  -> IMDb         https://www.imdb.com/title/tt38984207
  -> TheMovieDb   https://www.themoviedb.org/movie/1481955
  -> Trakt        https://trakt.tv/search/tmdb/1481955?id_type=movie
  （共 3 条，无 Douban）
```

- **根因**：本仓 `Provider/` 下只有 `MovieDbEpisodeGroupExternalId.cs` 实现了 `IExternalId`，**没有 `DoubanExternalId`**（全仓 `grep IExternalId` 仅 1 命中）。
- Emby 通过程序集扫描自动发现 `IExternalId` 实现；PRO 的 `StrmAssistant/Provider/DoubanExternalId.cs:11`（`IExternalId, IHasWebsite`，`Supports` = Movie \| Series \| Season，`UrlFormatString` → `movie.douban.com/subject/{0}/`）因此能在条目页渲染**豆瓣链接/图标**。
- 影响：豆瓣 ID 已写入元数据，但 UI 上**看不到豆瓣入口**——用户所问「图标」即指此项。

### 2.8 季级匹配全未命中（已知限制）

```
DoubanAssist - No douban match for: 第 1 季      ×≈20
DoubanAssist - Matched 夫妻的博弈 -> subject 37069873   （剧集主条目命中）
```

- 本仓季匹配仅靠**标题搜索**（`FindSubjectAsync:798-835`：`{剧名} 第N季` → 中文数字 → 从 suggest 里挑带「季」的）。
- 结果：剧集主条目能命中，**季条目几乎全部落空**。
- 对照 PRO：PRO 用 `Dto/Douban/DoubanSeasonsResponse`（含 `is_released`）+ `BuildDoubanCacheTask.UpdateSeasonMap()` 做**季映射表**，命中率结构性更高。详见优化方案 **D3**。

### 2.9 suggest 匹配质量（非阻塞）

- `天才，女友 第1季` → 误命中 `我的天才女友 第一季`（`DoubanAssist - No douban match for: 天才，女友`）。
- 纯季名 `第 1 季` 必然无匹配。
- 建议后续加**年份 + 类型**双校验。
