## 二、实现要点

### 2.1 `DigitsAsTmdbId`
- **接入点**：`EnhanceChineseSearch.CacheIdsFromTextParamsPrefix`（已有的 ID 前缀匹配逻辑之后）。
- **逻辑**：当开关开启、搜索词为**纯数字**且前面的 `imdb`/`tmdb=`/`tvdb=` 前缀匹配未命中时，把搜索词映射为 `AnyProviderIdEquals = { tmdb: digits }` 精确匹配，并清空 `SearchTerm`。
- **形态**：与现有 provider 匹配完全同构，零新依赖。

### 2.2 `MixedChineseVariants`
- **核心**：新增 `LanguageUtility.NormalizeChineseVariants()`，做字符级归一化：
  - 全角 ASCII（U+FF01–U+FF5E）→ 半角
  - 全角空格（U+3000）→ 半角空格
  - 中点（·/・）丢弃
  - 各类连字符/破折号（U+FF0D/U+2010–U+2014）→ `-`
  - 中文统一转简体（复用现有 CHTCHSConv）
- **索引侧**：`RebuildFts` 在 `ApplySimplifiedSweep` 之后追加 `ApplyVariantsSweep`（开关开启时才执行），对 FTS 表逐行做变体归一化写回——保证索引侧与查询侧规则一致。
- **查询侧**：`NormalizeSearchTerm` / `NormalizeQueryTerm` 在开关开启时改走 `NormalizeChineseVariants`。
- **索引一致性**：开关切换时在 `PluginOptionsStore` 触发 `ScheduleIndexRebuild()` + `NotifyPendingRestart()`（改归一化规则必须重建索引）。

### 2.3 `ShowMediaInfo`
- **破译来源**：PRO 反编译 `strings.txt` 还原出完整 JS（`ItemsView.prototype.getViewSettingDefaults` 包裹）。
- **逻辑**：搜索结果页（`params.type === 'search'`）读取当前 `data-searchtype` tab：
  - `Movie`/`Series`/`Season` → 追加 `CommunityRating`, `CriticRating`
  - `Movie`/`Episode`/`Video` → 追加 `Container`
- **接入点**：`strmassistant.js` 的 `ui` 模块新增 `patchSearchMediaInfo()`，在 `init()` 中调用；`ShortcutMenuHelper.cs` 通过 `window.__saUI.showMediaInfo` 传递开关。

## 六、设计取舍说明

- **未采用 PRO 的"统一多选偏好"范式**：社区版已有 `ExcludeOriginalTitleFromSearch` 等散开关，本次按**现有风格**新增独立 bool，避免重构带来的回归风险；后续如需统一为 `SearchTuningPreferences` 多选，可在此基础上一键归并。
- **`MixedChineseVariants` 未引入异体字字典**：PRO 的完整异体字映射在加密资源里，社区版采用**零依赖的字符级归一化**（全角/标点/简繁），覆盖常见场景且易于维护；如需扩展异体字表，可在 `NormalizeChineseVariants` 的 switch 分支上增量添加。
